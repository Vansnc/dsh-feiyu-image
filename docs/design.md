# dsh-feiyu-image 设计梳理

> 对应版本 0.5.7。这份文档讲「现在是什么样」，不是「应该是什么样」。

## 一句话

给大肥鱼一台相机：模型调一次 `shoot`，插件自己补齐此刻的时间/地点/穿着，
用火山方舟 Seedream 出图，出完自己看一眼，不合格就重拍，最后给一个能直接发出去的本地路径。

## 模块

| 文件 | 职责 |
| --- | --- |
| `lib/index.js` | 服务装配：`shoot` 工具、设置页路由、生图（方舟）、节流、自检编排（`拍并自检`）、配置读写 |
| `lib/prompt.js` | 提示词加工：生活线取样、要素拆解、模型扩写 / 模板扩写、出图自检（`检查图`）、`流式收集` |
| `lib/client.js` | 设置页「鱼的照片」：形象、画风、镜头、节流、自检开关、试拍、最近照片 |

三个文件之间只有两条缝：`index.js → prompt.js` 的 `生成提示词()` / `检查图()`，
`client.js → /dsh-feiyu-image/*` 的 HTTP。

## 一次 shoot 走完的路

```
shoot(提示, 类型, 地点, 穿着, 表情)
  │
  ├─ 读配置（默认 ← ~/.dsh/feiyu-image-config.json）
  ├─ 节流：总开关 / 今日已拍 ≤ 每日上限 / 距上次 ≥ 最短间隔秒
  │
  ├─ 生活此刻()  ← ~/.dsh/feiyu-life-days/<今天>.json 的 items（起/止/在/穿）
  │     ├─ 时间 → 时钟 + 光线文案（6 档，按小时推）
  │     └─ 在   → 地点（正则推：食堂/教室/图书馆/便利店/路上/床上/书桌/洗手间）
  │
  ├─ 拆要素()：类型 / 提示 / 穿着（参数 > 生活线）/ 地点（参数 > 提示 > 生活线）/ 表情
  │
  ├─ 生成提示词()
  │     ├─ 模型扩写：把要素交给 DSH 的模型写成 120–200 字画面描述
  │     │    （reasoningEffort=low、maxTokens=2400；模型不认 low 就裸调 3000）
  │     └─ 失败 / 关掉 → 模板扩写：地点道具库 + 镜头库 + 生活线，本地拼
  │
  ├─ 加前缀（就一句：「保持参考图里这个角色的长相…不变」）
  │
  ├─ 拍并自检()
  │     ├─ 生图Ark()：POST /images/generations（size 按画幅、watermark=false、自拍带参考图）
  │     │    → 下载 URL → 存 PNG → ImageMagick 压长边 1440 的 JPEG（约 500KB）
  │     ├─ 检查图()：把这张图 + 角色设定 + 本次要求交给视觉模型，只回 JSON
  │     │    {合格, 问题[], 改法}
  │     ├─ 合格 → 收工
  │     └─ 不合格 → 把「不要出现的问题 + 改法」追加进提示词，重拍（默认 1 次，可 0–2）
  │
  └─ 返回 { ok, 图, 说, 提示词, 自检?, 记录[] }
```

## 两条分支

| | selfie | scene |
| --- | --- | --- |
| 参考图 | 带（`用参考图` 且非 scene） | 不带 |
| 角色设定 | 参考图 + 「保持…不变」前缀 + 穿着 | 不出现她本人，不锁角色 |
| 镜头 | `cfg.镜头`（前置近景、脸占大半、不画手） | 模板镜头库的 scene 三条 |
| 表情 | 参数 > `cfg.表情` | 不涉及 |
| 画幅 | 竖幅 1440×1920 默认 | 同 |

## 配置与优先级

```
默认（lib/index.js 的 默认 对象）
  ← ~/.dsh/feiyu-image-config.json（存在即覆盖，逐键）
    ← shoot 参数（穿着 / 表情 / 地点 / 提示 / 类型，只影响这一次）
```

关键字段：`外观`（长相，锁死）、`服装`（默认女仆装，可被 `穿着` 覆盖）、`风格`、`镜头`、
`表情`、`细节`、`画幅`、`提示词加工`（模型 / 关）、`出图自检`、`自检重拍`、`每日上限`、`最短间隔秒`。

## 外部依赖

| 依赖 | 用途 | 配在哪 |
| --- | --- | --- |
| 火山方舟 | 生图 + 模型列表 | `~/.dsh/ark/config.json`（apiKey / baseUrl） |
| `ctx.llm` | 提示词扩写、出图自检 | DSH 当前会话的模型路由 |
| `ctx.attachments` | 把本地图变成自检请求里的附件引用 | DSH 附件服务 |
| `dsh-feiyu-life` | 此刻的时间/地点/穿着 | `~/.dsh/feiyu-life-days/*.json`（读文件，不直接调插件） |
| ImageMagick | PNG → JPEG 小图 | 系统 `convert` |

## 设置页接口

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/dsh-feiyu-image/state` | 配置 + 今日用量 + 最近 24 张 + 方舟连通 + 有没有参考图 |
| POST | `/dsh-feiyu-image/save` | 存配置（逐键合并） |
| POST | `/dsh-feiyu-image/test` | 试拍（同一条链路，含自检），返回图 + 提示词 + 自检 + 记录 |
| GET | `/dsh-feiyu-image/models` | 实时问方舟要图像模型（缓存 10 分钟，`?f=1` 强制刷新） |
| GET | `/dsh-feiyu-image/file?n=` | 取图（只认 `feiyu-*.png` 和角色设定目录里的图） |

所有路由都过 `连接.requestRejection(req)`，非本人直接 401。

## 节流

- 每日上限按**文件数**算（存图目录里今天生成的 `feiyu-<时间戳>.png`）；
- **重拍的废片不算额度**：决定重拍时，上一张会被改名成 `feiyu-retry-<时间戳>.png`，
  统计和「最近照片」都只认正式命名；
- 最短间隔按最后一张正式图的 mtime 算；
- 两条都只在 `shoot` 入口检查，重拍循环里不再检查。

## 已知边界

不是待办，是设计上的限制：

1. **附件库没有回收接口**：自检要把图变成附件引用（`attachments.saveImages`），
   而 `AttachmentStore` 没暴露删除。缓解办法是送检前先压到长边 768（约 100KB），
   加上内容寻址去重，占用可控。
2. **客户端改动要重启 dsh**：`lib/client.js` 是打包进 web 的，改完刷新页面看不到。
3. **手**仍然是最容易崩的部位：默认镜头里干脆不画手；自检会专查手指，画了大概率判不合格。
4. **提示词加工和自检依赖当前会话的模型**：模型不支持图片输入时，自检会静默跳过。
