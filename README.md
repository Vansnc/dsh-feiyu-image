# dsh-feiyu-image

[![npm](https://img.shields.io/npm/v/dsh-feiyu-image)](https://www.npmjs.com/package/dsh-feiyu-image)
[![license](https://img.shields.io/npm/l/dsh-feiyu-image)](./LICENSE)
[![node](https://img.shields.io/badge/node-%E2%89%A522-informational)](https://nodejs.org/)

给陪伴角色一个相机：模型调一个工具就能「拍一张」，**自动带上她此刻的穿着和所在场景**，
存成本地图片，回复里写 `![描述](路径)` 就能发到 QQ。

生图走 **火山方舟 Seedream 5.0**（默认 `doubao-seedream-5-0-pro-260628`，挂了自动换 flash）。
设置页的模型下拉是**实时问方舟要的**（`GET /models`，筛图像生成），新模型上线会自动出现，也能手填。

有参考图之后，**角色形象是锁死的**：把 `~/.dsh/feiyu-image/角色设定/正面.jpg` 传进去，
脸、发色渐变、鲸鱼鳍耳、呆毛、鲸鱼尾都跟着这张图走。画风锁二次元，
角色示例是**鲸鱼娘**（深蓝渐变长发、鲸鱼鳍耳、鲸鱼尾），衣服是可变量。

## 为什么不是 dsh-image-studio

[dsh-image-studio](https://github.com/meliodascz89/dsh-image-studio) 停在 0.1.7（2026-08），
依赖 `@deepseek-ai/dsh-tools ^0.1.0-rc.6`、`dsh-settings ^0.1.1-rc.2`，跟 dsh 0.2.x 不兼容，
要装得给确切版本盖豁免（可能崩、可能丢数据）。而这里真正有用的只有一个工具，就自己写了。

## 能力

| 工具 | 说明 |
| --- | --- |
| `shoot` | `提示` + `类型`（`selfie` 自拍 / `scene` 只拍场景）+ 可选 `地点`/`穿着`/`表情` → 生成并保存 |

- **提示词自动拼**：固定特征 + 此刻穿着（读 `dsh-feiyu-life` 的今日剧本）+ 场景 + 光线 + 画风；
- **两级提示词加工**：模型扩写（用 DSH 当前模型写 120–200 字的完整画面描述）/ 模板扩写（本地拼，不花钱）；
- **出图自检**：出完让视觉模型看一眼——角色跑偏、画风错、画崩（多手多指）、画面里有文字水印，
  都算不合格，自动带着问题重拍一次（重拍的废片不计入每日额度）；
- **两条分支**：自拍锁角色、拍场景不塞人；
- **竖幅 1440×1920**，出图后自动压一张长边 1440 的 JPEG（约 500KB），QQ 发大图容易渲染成空泡；
- **节流**：默认每天 8 张、两次至少隔 30 秒（配置可调）；
- 生图失败会返回原因，不会卡住整轮对话。

## 安装

```sh
dsh plugin --profile web add dsh-feiyu-image
```

需要 `~/.dsh/ark/config.json`（方舟的 `apiKey` 和 `baseUrl`）。

## 配置

`~/.dsh/feiyu-image-config.json`（没有就用默认；设置页改的就是这个文件）：

```json
{
  "总开关": true,
  "模型": "doubao-seedream-5-0-pro-260628",
  "备用模型": "doubao-seedream-5-0-flash-260915",
  "用参考图": true,
  "参考图": "",
  "外观": "鲸鱼娘：深蓝色及腰长卷发，发尾渐变成浅蓝；头顶一撮鲸鱼尾形状的呆毛；两侧鲸鱼鳍形状的耳；蓝色大眼",
  "服装": "深蓝色长袖女仆连衣裙，白色大围裙，身后一条深蓝色鲸鱼尾巴",
  "风格": "日系精细插画，赛璐璐分色加柔和厚涂阴影，清晰线稿，非 Q 版",
  "镜头": "手机前置自拍近景，脸占画面大半，平视或微微仰起下巴看镜头，画面里不出现手",
  "表情": "嘴角带一点得意的笑，眼睛看进镜头",
  "细节": "发丝高光、耳鳍的半透明质感、脖颈阴影、背景里的生活杂物",
  "画幅": "竖幅",
  "提示词加工": "模型",
  "出图自检": true,
  "自检重拍": 1,
  "每日上限": 8,
  "最短间隔秒": 30,
  "存图目录": ""
}
```

| 字段 | 说明 |
| --- | --- |
| `外观` / `服装` | 长相和默认衣服，一字不差写进提示词；`服装` 会被 `shoot` 的 `穿着` 参数覆盖 |
| `镜头` | 自拍构图。默认不拍手——前景的手是最容易画崩的地方 |
| `画幅` | `竖幅` 1440×1920 / `方形` 2048×2048 / `横幅` 1920×1440 |
| `提示词加工` | `模型`（DSH 当前模型扩写）/ `关`（只用本地模板） |
| `出图自检` / `自检重拍` | 出图后要不要看图、不合格最多重拍几次（0–2） |
| `存图目录` | 留空 = `~/.dsh/feiyu-image/` |

## 用法

模型侧：

```
shoot 类型=selfie 提示="刚洗完澡，敷着面膜，头发有点乱" 表情=困
shoot 类型=scene  提示="宿舍窗台上的绿萝，傍晚的光"
```

回复里用 markdown 引用路径即可发图（QQ 桥会把 `![描述](绝对路径)` 抽成图片段）。

## 成本与耗时

- 单张 **20–40 秒**（含自检；要重拍就更久）；
- 出的是竖幅 1440×1920 PNG（原图 5–8MB），另压一张约 500KB 的 JPEG 小图；
- 按方舟 Seedream 的图片生成计费；
- 提示词扩写和自检走 DSH 当前的模型，用的是文本/视觉 token，不额外花钱。

## 已知边界

- 中文文字（黑板、书页）容易糊成乱码，尽量别让画面里出现要认的字；
- **手**仍然是最容易崩的地方，所以默认镜头里干脆不画手；要拍手部动作的话，自检大概率会判不合格；
- 自检依赖视觉模型：当前模型不支持图片输入时，自检会静默跳过，日志里写「自检跳过」；
- 依赖 `dsh-feiyu-life` 才有「穿着/场景」；没装也能用，只是提示词里少这两项；
- 改了 `lib/client.js`（设置页）要重启 dsh 才看得到。
